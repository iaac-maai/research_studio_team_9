## Features (proposed order)

Done in the prototype:

- Revit Inspect Element (insulation layer, mapped product, thermal check)
- Thermal schedule export to Excel
- Rule-based check: PASS / FAIL / CANNOT VERIFY

Next:

1. Replace hardcoded material-to-product mappings with data-driven configuration
2. Make project requirements configurable
3. PDF data-sheet extraction with evidence links
4. AI-assisted product candidate matching, keeping compliance rules explainable
5. Multi-layer assembly check (U-value)
6. Controlled Excel-to-Revit update workflow (preview and user approval)
7. Design assistant (conversational search of the catalogue)
